Avance técnico

Comparación de Datos Meteorológicos

Este avance analiza y compara dos fuentes públicas de datos meteorológicos utilizadas para estimar la generación fotovoltaica potencial de CEME1 en SAM: el Explorador Solar de Chile y NASA POWER. La comparación se centra en las principales variables de irradiancia solar: GHI, DNI y DHI.

Objetivo y alcance del avance

En esta etapa del trabajo se analiza la información meteorológica utilizada para estimar la energía fotovoltaica potencial de la planta CEME1 mediante el software SAM. El objetivo principal es comparar dos fuentes públicas de datos meteorológicos reconocidas y utilizadas en análisis energéticos: el Explorador Solar de Chile y NASA POWER.

El Explorador Solar de Chile permite obtener información meteorológica asociada a la ubicación de CEME1, en la comuna de María Elena, considerando coordenadas geográficas, altitud y variables solares relevantes para simulación fotovoltaica. Sin embargo, la información disponible corresponde a un año meteorológico típico, por lo que no representa directamente las condiciones específicas del año 2025.

Por otra parte, NASA POWER permite descargar datos meteorológicos horarios recientes para la zona de estudio, incluyendo información correspondiente al año 2025. Esta fuente se incorpora debido a que permite reconstruir una serie meteorológica contemporánea al período de análisis operacional considerado en el proyecto.

A partir de ambas bases de datos se realizará una comparación de variables relevantes, principalmente GHI, DNI y DHI, con el propósito de evaluar diferencias entre fuentes, revisar su coherencia y determinar cómo dichas diferencias pueden afectar la estimación de generación fotovoltaica potencial en SAM.

Flujo de trabajo de comparación meteorológica

01

Selección de fuentes

Se definen dos bases meteorológicas públicas: Explorador Solar de Chile y NASA POWER.

02

Descarga de datos

Se descargan datos meteorológicos para la ubicación de CEME1 en María Elena.

03

Procesamiento NASA POWER

Se utiliza Python para transformar la serie 2025 en un archivo CSV compatible con SAM.

04

Carga en SAM

Ambos archivos meteorológicos se cargan sobre la arquitectura de CEME1 previamente configurada.

05

Comparación de variables

Se comparan GHI, DNI y DHI mediante métricas anuales, mensuales y perfiles horarios.

06

Análisis posterior

Las diferencias entre fuentes serán vinculadas con la generación energética estimada en SAM.

Relación con SAM

El archivo del Explorador Solar presenta la ventaja de estar disponible en un formato directamente compatible con SAM, por lo que puede ser cargado sin un procesamiento significativo.

En cambio, los datos descargados desde NASA POWER requieren ser procesados previamente. Para ello, se utiliza un script desarrollado en Python, ejecutado desde Visual Studio Code, cuyo objetivo es transformar la base meteorológica descargada en un archivo CSV compatible con SAM.

Finalmente, se obtienen dos archivos meteorológicos de entrada: uno basado en el año meteorológico típico del Explorador Solar y otro construido a partir de la serie horaria 2025 de NASA POWER.

Resultado del avance

Base meteorológica comparativa para simulación energética

La comparación entre Explorador Solar TMY y NASA POWER 2025 permite construir una base meteorológica trazable para evaluar posteriormente el impacto de la fuente de datos sobre la generación energética simulada de CEME1 en SAM.
