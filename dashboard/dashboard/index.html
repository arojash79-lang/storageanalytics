Perfil horario AC/DC

El perfil horario total anual puede suavizar la configuración Este/Oeste, especialmente por la baja inclinación de 5°. La validación de la arquitectura debe realizarse separando los submodelos Este y Oeste.

El JSON comparativo disponible contiene perfil horario promedio anual total, no detalle diario por submodelo.

Verificación Este/Oeste

Este = SC01 + SC03 + SC05. Oeste = SC02 + SC04 + SC06. Se requiere generar un JSON horario por submodelo para validar Este/Oeste. El perfil total anual no basta para confirmar visualmente la arquitectura V invertida.

El total puede verse como campana o plateau por la baja inclinación de 5°.

POA Este/Oeste mensual

El TMY representa un año meteorológico típico y tiende a mostrar mayor simetría Este/Oeste. NASA POWER 2025 representa un año histórico, por lo que puede mostrar asimetrías horarias y estacionales.

NOTA METODOLÓGICA

SAM NASA 2025 representa una simulación técnica de generación FV bajo meteorología histórica 2025 y pérdidas configuradas en SAM. No incorpora fallas, mantenimientos ni indisponibilidad técnica real de CEME1. Por ello, el residuo SAM − CEN disponible se interpreta como una discrepancia técnico-operacional, no como error puro del modelo.

Limitaciones metodológicas

  • No se dispone de irradiancia in situ en CEME1.
  • La validación es indirecta, usando referencias operacionales oficiales del CEN.
  • SAM no modela fallas reales, mantenimientos no informados ni indisponibilidad técnica histórica.
  • Las reducciones CEN se interpretan como curtailment operacional recuperable potencialmente por el BESS.
  • El pronóstico centralizado CEN es una referencia operacional, no una verdad física absoluta.

Conclusión Bloque 1

La comparación entre SAM NASA 2025, el pronóstico centralizado CEN y el CEN disponible permite cerrar el bloque FV mediante una descomposición operacional del residuo. Esta estructura separa la brecha entre simulación técnica, pronóstico operacional y reducciones CEN, entregando una base consistente para avanzar hacia la simulación del BESS y la valorización de energía reducida.
